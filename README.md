# 🤖 FutureGrade AI: Student Performance Prediction System

An interactive machine learning dashboard built with **Streamlit** and **Scikit-Learn** that predicts whether a student will pass or fail based on their academic habits.

## 📌 Features
* **Interactive ML Training:** Tweak model settings (Max Depth, Criterion) live on the screen.
* **Real-time Tree Visualization:** Renders your Decision Tree structure instantly on a custom background.
* **Instant Sandbox Predictor:** Input attendance, study hours, and subject data to get an immediate prediction.
* **Projector Optimized:** High-contrast, large text designed perfectly for classroom presentations.

## 🛠️ Tech Stack
* **Frontend:** Streamlit, Custom HTML5 & CSS3
* **Machine Learning:** Scikit-Learn (Decision Tree Classifier)
* **Data Processing:** Pandas
* **Visualization:** Matplotlib
